# Pet Memorial API

A Laravel JSON API for pet memorials, a memorial blog and a small shop. It includes Sanctum authentication, email verification and password-reset OTPs, comments, likes, friendships, in-app notifications, admin content management and tag-based HTTP response caching.

## Requirements

- PHP 8.3+ (the application is developed on PHP 8.5)
- Composer
- Node.js and npm for frontend assets
- Redis for the public response cache (the application uses the `predis` client, so the PHP Redis extension is not required)
- SQLite by default; any Laravel-supported database can be configured in `.env`

## Setup

```bash
composer setup
```

The setup script installs dependencies, creates `.env` and the SQLite database if needed, generates the application key and runs migrations. Then seed the demo data:

```bash
php artisan migrate --seed
```

Start the development stack:

```bash
composer dev
```

That runs the API server, queue worker, log viewer and Vite. Run the scheduler separately when testing email verification, password-reset OTP pruning or Sanctum token pruning:

```bash
php artisan schedule:work
```

The public read endpoints require a running Redis server at the address configured by `REDIS_HOST` and `REDIS_PORT`.

## Seeded accounts

All demo accounts use the password `password`:

- `admin@example.com` — administrator
- `user1@example.com` through `user24@example.com` — regular users

## API documentation

OpenAPI documentation is generated by Scramble:

- Local UI: `/docs/api`
- JSON document: `/docs/api.json`

In production the docs are restricted to authenticated administrators through the `viewApiDocs` gate.

## Useful commands

```bash
php artisan test --compact   # run the test suite
vendor/bin/pint              # format PHP code
composer analyse             # run Larastan static analysis
composer rector:dry          # preview automated refactors
composer audit --abandoned=report  # check dependencies for vulnerabilities and abandoned packages
```
